# Module: Memory    Owner: David Molina
## 1. What was implemented

`coordinator.admission.reserve` runs before case/subtask INSERTs in the same
transaction. A PostgreSQL advisory try-lock serializes admission across API
processes; busy admission returns 503 + Retry-After. Reservations live in
server-owned subtask params; terminal cases stop counting automatically.
Caller-supplied reservations are discarded.

Limits default to zero (disabled to preserve existing scenarios).
Set `M1_MAX_ACTIVE_CASES`, `M1_MAX_CASE_INPUT_BYTES` and/or
`M1_MEMORY_BUDGET_BYTES`; the latter requires `M1_TASK_BASE_BYTES > 0`.
`M1_OPERATION_BASE_BYTES` JSON can supply per-operation model estimates.
Reservation = sum(model base + S3 ContentLength * input multiplier), default
multiplier 4. Oversized cases return 413; exhausted reservations return 503.
Drain existing cases before enabling memory budgets: unreserved active cases
fail closed. This is conservative accounting, not a measurement of free RAM.
Compressed size cannot guarantee decoded memory; calibrate with real inputs.
A worker still processing a terminal case is not covered by case accounting;
cgroups and process supervision remain necessary for hard isolation.

## 2. Operating systems concept

RSS counts resident pages; PSS apportions shared pages. RSS sums double-count
fork-shared weights. Linux cgroups enforce a memory boundary; admission
reduces excess accepted work before it reaches the outbox.

## 3. Measurement method

`experiments/m1_memory/scripts/measure.py` loads each real model, samples
RSS/PSS every 100 ms and runs three inferences. Native Windows inputs are
synthetic text, a blank 320x320 image and two seconds of silence, generated by
`fixtures.py`. These are smoke profiles, not workload capacity estimates.
Raw JSON/CSV in `experiments/m1_memory/results/native/` records host/input
details. PSS is null on Windows; sampled peaks can miss brief allocations.

Reproduce from repo root (PowerShell):

```powershell
uv run --all-packages --all-extras python experiments/m1_memory/scripts/fixtures.py "$env:TEMP/madp-m1-inputs"
uv run --all-packages --all-extras python experiments/m1_memory/scripts/measure.py image "$env:TEMP/madp-m1-inputs/blank.png" --out experiments/m1_memory/results/native
```

Use text/chat.txt and audio/silence.wav for the other pools. Linux procedure:

```sh
docker build -f experiments/m1_memory/Dockerfile -t madp-m1 .
uv run --all-packages --all-extras python experiments/m1_memory/scripts/fixtures.py /tmp/m1-inputs
uv run --all-packages python experiments/m1_memory/scripts/container_sweep.py image /tmp/m1-inputs
docker run --rm --memory=2g --memory-swap=2g -v /tmp/m1-inputs:/inputs:ro -v "$PWD/experiments/m1_memory/results/linux:/results" madp-m1 image /inputs/blank.png --out /results --sharing own
docker run --rm --memory=2g --memory-swap=2g -v /tmp/m1-inputs:/inputs:ro -v "$PWD/experiments/m1_memory/results/linux:/results" madp-m1 image /inputs/blank.png --out /results --sharing shared
```

Repeat for audio/text. Sharing includes parent and three idle children:
private spawned models versus parent-loaded fork/CoW. It measures loaded
weights, not concurrent inference; forked native runtimes must not be assumed
safe for inference. The sweep records exit code and Docker OOMKilled before
removing its containers. OOM followed by a successful higher-limit run proves
isolated process recovery only, not broker requeue recovery.

## 4. Results

Windows 11, CPython 3.13, 2026-11-10 (MiB = 2^20 bytes):

| Model | Loaded RSS MiB | Sampled inference peak MiB | PSS | Smallest cgroup limit |
|---|---:|---:|---|---|
| Bilingual rules v1 | 33.31 | 33.41 | unavailable | unmeasured |
| YOLOv8n COCO CPU | 238.70 | 374.61 | unavailable | unmeasured |
| faster-whisper tiny/int8 CPU | 158.35 | 240.98 | unavailable | unmeasured |

Admission self-check passed for budget/active limits, overload, oversized
reservation and caller spoofing. It uses SQL fakes, not PostgreSQL integration.

## 5. Interpretation

Image/audio imports and inference dominate the simple rule model. These
figures do not justify production limits. Docker is not installed on this
host: Linux PSS, smallest surviving limits, provoked OOM, fork/CoW comparison
and distributed worker burst/requeue recovery remain unmeasured. Scripts are
provided; no results are invented. The fake-worker E2E does not prove
real-model OOM recovery. Native traces cover repeated inference in one process,
not a distributed burst.
